- ⚠️ Fake loading → **error, again and again** 😂
- 😂 Ends with a "Gotcha! Ye prank hai" reveal

## How to use
Open the site, send the link to a friend, watch them hit "Try Again" forever.

## Customize
Edit the `<script>` config at the bottom of `index.html`:
- `PRANK_NAME` — name shown on the reveal screen
- `REVEAL_AFTER` — how many errors before the prank is revealed
